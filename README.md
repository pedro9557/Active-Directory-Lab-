# Active-Directory-Lab-
Hands-on Active Directory lab demonstrating Windows Server domain administration, user and group management, DNS, DHCP, and Windows client domain joining. 


<h2></h2> Environments Used
- Windows Server 2022
- Windows 10
- Power Shell
